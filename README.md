# Recruitment & Talent Management

## Overview

This repository showcases practical knowledge and resources related to recruitment and talent management. It focuses on the key stages of the recruitment lifecycle, from identifying hiring requirements to candidate selection and onboarding.

The portfolio is designed to demonstrate practical understanding of recruitment processes, candidate evaluation, documentation, and talent management practices.

* Candidate Sourcing
* Resume Screening

* Candidate Evaluation
* Selection Process
* Offer Management
* Employee Onboarding
* Talent Management

## Recruitment Process

The recruitment workflow covered in this portfolio follows these key stages:

1. Identify manpower requirements
2. Prepare job description
3. Source candidates
4. Screen applications
5. Shortlist suitable candidates
6. Conduct interviews
7. Evaluate candidates
8. Select the candidate
9. Complete documentation
10. Coordinate onboarding

## Recruitment Metrics

Key recruitment metrics that can be monitored include:

| Metric                | Purpose                                    |
| --------------------- | ------------------------------------------ |
| Time to Hire          | Measures the time taken to fill a position |
| Time to Fill          | Measures recruitment cycle duration        |
| Cost per Hire         | Measures recruitment cost                  |
| Offer Acceptance Rate | Measures candidate acceptance              |
| Source of Hire        | Identifies effective recruitment sources   |
| Selection Ratio       | Measures candidate selection efficiency    |
| Employee Retention    | Evaluates hiring effectiveness             |
